## Problem Descriptions & Examples

1. **Even or Odd**
   - Input an integer.
   - Check whether it is even or odd.

2. **Positive, Negative, or Zero**
   - Input a number.
   - Print whether it is positive, negative, or zero.

3. **Largest of Three Numbers**
   - Input three numbers.
   - Find and print the largest.

4. **Sum of Digits**
   - Input: `1234`
   - Output: `10`

5. **Reverse a Number**
   - Input: `12345`
   - Output: `54321`

6. **Palindrome Number**
   - Input: `121`
   - Output: `Palindrome`

7. **Prime Number Check**
   - Input a number.
   - Check whether it is prime.

8. **Factorial**
   - Input: `5`
   - Output: `120`

9. **Multiplication Table**
   - Input: `7`
   - Print its table from 7 × 1 to 7 × 10.

10. **Fibonacci Series**
    - Input: `7`
    - Output: `0 1 1 2 3 5 8`

11. **Find the Second Largest Number in an Array**
    - Input an array of numbers.
    - Find and print the second largest element.

12. **Count Vowels and Consonants in a String**
    - Input a string.
    - Count and print the number of vowels and consonants.

13. **Find the Frequency of Each Digit in a Number**
    - Input a number.
    - Count and print the frequency of each digit.

14. **Sort an Array in Ascending Order**
    - Input an array of numbers.
    - Sort and print the array in ascending order.

15. **Check Whether Two Strings are Anagrams**
    - Input two strings.
    - Check whether the two strings are anagrams of each other.
