# C Language Learning & Practice

My personal repository for learning C programming from scratch. Contains code snippets, practice problems, data structures, and small projects as I learn.

## Structure
- Programs covering core concepts (loops, pointers, dynamic memory, file I/O)
- Data structure & algorithm implementations
- Practice questions and code exercises
- Small CLI programs / mini games

## Setup & Compilation
Compile any program using GCC or any standard C compiler:

```bash
gcc filename.c -o output
./output
```
